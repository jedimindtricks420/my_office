# Documentation Standards

## Общие правила

- Пиши коротко и структурированно.
- Описывай текущее подтверждённое состояние.
- Не смешивай факты, решения и открытые вопросы.
- Используй один канонический файл для каждого типа информации.
- Используй относительные ссылки внутри репозитория.
- Не дублируй сведения без необходимости.
- Не храни секреты и конфиденциальные данные.

## Обновление

При изменении системы обновляй соответствующую документацию в том же изменении. Значимые архитектурные решения оформляй отдельным ADR в каталоге `adr/`.
