# my_office

Центральный monorepo компании для проектов, документации, спецификаций, задач и инструкций ИИ-агентам.

## Принцип

GitHub repository is the source of truth.

Корневой файл [AGENTS.md](AGENTS.md) содержит канонические инструкции для всех ИИ-агентов. Файлы [CLAUDE.md](CLAUDE.md) и [GEMINI.md](GEMINI.md) направляют соответствующих агентов к этим инструкциям.

## Структура

- `docs/` — общая документация и архитектурные решения.
- `projects/` — отдельные проекты компании.
- `shared/` — общие документы, скрипты и пакеты.

Проекты добавляются в `projects/<project-name>/` по структуре, описанной в корневом [AGENTS.md](AGENTS.md).

На текущем этапе проекты в репозитории не определены.
