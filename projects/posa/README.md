# POSA

B2B/B2C платформа дистрибуции цифровых товаров (ваучеров/ключей): мерчанты
продают ваучеры (оффлайн с QR-чеком или онлайн по SMS), клиенты активируют их
через брендированные страницы магазинов или PWA-кошелёк, привязывая код к
Apple/Google Wallet.

Это каталог документации в `my_office`. Исходный код — отдельно, вне этого
репозитория, см. [AGENTS.md](AGENTS.md).
