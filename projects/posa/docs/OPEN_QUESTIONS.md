## Расхождения между документацией проекта и кодом

1. **Python/Telegram.** `.github/copilot-instructions.md` упоминает "Python
   (Pyrogram) для одного Telegram-вендора", `.gitignore` содержит правила для
   каталога `telegram-key-bot/`, но такого каталога в `/home/admin1/posa/` не
   найдено. При этом `docs/PRD.md` прямо утверждает: "система не использует
   Python-скриптов для автоматизации Telegram", а уведомления реализованы
   через `TelegramBot`/`services/telegramService.js` на Node.js. Неясно: этот
   Python-модуль удалили, он живёт в другом каталоге/репозитории, или
   `copilot-instructions.md`/`.gitignore` устарели.
2. **PRD актуальность.** `docs/PRD.md` датирован 2025-12-17 и описывает
   только интеграцию Rokky, без Dr.Web/ManaStore/Alif/QR-платежей/Kassa —
   всё это уже есть в коде и в более поздних Prisma-миграциях (до
   2026-07-30). PRD не обновлялся вслед за кодом.
3. **`docs/BUSINESS_LOGIC.md`** помечен как "Версия 2.1 (исправленная по
   коду)" без указания даты — не проверялось построчно на 100% соответствие
   текущей схеме (36 моделей), только использован как контекст для
   OVERVIEW.md/DATABASE.md; сверка была выборочной, не исчерпывающей.

## Технические неопределённости

4. **`routes/apiV1.js`** — файл с моковыми/тестовыми данными
   (`TEST-100-AAAA`), не импортирован в `index.js`. Не выяснено: мёртвый код,
   черновик для будущей замены `apiV1Routes.js`, или используется где-то ещё
   (например, тестами/фронтендом напрямую) не через `index.js`.
5. **`manual_migration_qr_payment.sql`** в корне `activation-system/` —
   отдельный SQL-файл рядом с папкой `prisma/migrations/`. Не проверялось,
   был ли он применён вручную (в обход `prisma migrate`), это черновик одной
   из штатных миграций, или устаревший файл.
6. **Bootstrap vs Tailwind.** `.github/copilot-instructions.md` описывает
   фронтенд как "EJS + Bootstrap", но в `package.json` зависимостей Bootstrap
   нет — есть только `tailwindcss`. Не проверялось, подключается ли Bootstrap
   через CDN в самих `.ejs`/`public/` файлах (это не исключалось явно, но и
   не подтверждалось).
7. **Скрипты `bmad:*` в `package.json`** (`bmad:refresh`, `bmad:list`,
   `bmad:validate`, использующие `bmad-method`) — назначение, реальное
   использование и то, есть ли `bmad-method` в зависимостях, не выяснялось.
8. **Именование версии.** `V3_CHECK.txt` гласит "Using POSA-v3 as primary
   repo", git remote — `POSA-v3.git`, но самый первый коммит в истории
   называется "Initial commit: project migration to v2". Не критично, но
   нумерация версий в разных источниках не совпадает — не выяснялось, что
   именно считается v2 и что v3.
9. **`.htpasswd-studio`** (Basic Auth для `ppdev.namo.uz` → Prisma Studio) —
   существование файла и директива в Nginx подтверждены, но не проверялось
   содержимое (сколько учётных записей, когда обновлялись пароли).
