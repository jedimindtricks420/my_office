## Что подтверждено и работает

- **Backend** (`activation-system`, Node.js 20 + Express 5 + Prisma 6 +
  PostgreSQL 16) работает в Docker, контейнер `activation-system` up 2
  недели на момент проверки, слушает порт 4000 (плюс отдельный проброс 4001
  для `api.namo.uz`).
- **Nginx** маршрутизирует 8 поддоменов `*.namo.uz` на этот же backend по
  имени хоста; приложение само разруливает роль по `Host` в
  `middleware/checkSubdomain.js`. Подробности — [DEPLOYMENT.md](DEPLOYMENT.md).
- **Схема данных**: 36 моделей, 12 enum'ов, 28 миграций Prisma (с
  2025-02-11 по 2026-07-30) — задокументированы в [DATABASE.md](DATABASE.md).
- 185 объявлений HTTP-маршрутов (`router.get/post/put/delete`) по 14 файлам
  роутеров (из них 4 — в неиспользуемом `routes/apiV1.js`, см.
  OPEN_QUESTIONS.md) задокументированы в
  [API.md](API.md); аутентификация — сессии (`express-session` +
  `connect-pg-simple`, хранение в той же Postgres) с ролевыми middleware для
  сотрудников и отдельная OTP-по-телефону авторизация для клиентов.
- Три платёжных провайдера как webhook-интеграции (Click, Payme, Alifpay) +
  собственный QR-платёж, реквизиты — per-кассе в таблице `Kassa`, а не
  только в `.env`.
- PWA-кошелёк клиента + Android TWA-обёртка (`my-pwa/`, Bubblewrap) с
  публикацией на `wallet.namo.uz`.

## Известные проблемы / расхождения (подтверждены напрямую)

1. **`activation-db` (Postgres) проброшен на `0.0.0.0:7440`** — доступен не
   только с локального хоста. Совпадает с находкой прошлого security-аудита
   (2026-08-01); на 2026-09-05 не устранено. Не исправлялось в этой задаче
   по прямому указанию — задача была ограничена документированием.
2. **`test-payme-transaction.sh`** в корне `/home/admin1/posa/` содержит
   зашитый в код похожий на боевой ключ Payme и отслеживается git
   (`git ls-files` подтверждает). Тоже совпадает с прошлым аудитом,
   на 2026-09-05 всё ещё в репозитории.
3. **`ppdev.namo.uz`** публично проксирует Prisma Studio (полный доступ на
   чтение/запись БД через браузер) — защищено Basic Auth на уровне Nginx
   (`.htpasswd-studio`), но само по себе является нестандартной практикой
   выставлять админку БД в интернет даже за Basic Auth. См.
   [DEPLOYMENT.md](DEPLOYMENT.md).
4. **Собственная документация проекта неоднородна по актуальности**:
   `docs/PRD.md` (2025-12-17) не отражает добавленные позже Dr.Web/
   ManaStore/Alif/QR-платежи/Kassa; упоминание Python/Pyrogram в
   `.github/copilot-instructions.md` не подтверждается наличием
   соответствующего кода в репозитории. См.
   [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).
5. **Нет автоматических тестов** (jest/mocha/vitest не найдены) — только
   несколько ручных Node-скриптов для точечной проверки сценариев вручную.
