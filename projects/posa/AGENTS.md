## Известные особенности проекта (важно для агентов)

- Роль пользователя на фронтенде определяется **поддоменом** запроса
  (`middleware/checkSubdomain.js`): `wallet.` → клиент, `merchant.` →
  мерчант, `vendor.` → вендор, `office.` → админ/офис, остальное → public.
  Одно и то же Express-приложение (порт 4000) обслуживает все поддомены —
  маршрутизация по хостам делается в Nginx на уровне сервера, не в коде.
- Реальные роли пользователей (`Role` enum в Prisma) шире, чем 4 поддомена:
  `admin`, `merchant`, `vendor_user`, `financial_mgr`, `content_mgr`,
  `support_agent`, `kassa_admin`, `kassa_viewer`. Авторизация внутри `/admin`
  дополнительно разграничена по роли через middleware в `middleware/auth.js`
  (`allowFinance`, `allowContent`, `allowSupport`, `allowOfficeDashboard`,
  `ensureKassa` и т.д.) — не только по факту логина.
- В БД есть модель `Kassa`, которая хранит платёжные реквизиты (Click/Payme/
  Alif ключи и merchant ID) **как поля таблицы**, отдельно от `.env` —
  система поддерживает несколько касс с разными платёжными провайдерами
  одновременно. См. [DATABASE.md](docs/DATABASE.md).
- В репозитории есть файл `routes/apiV1.js` с моковыми данными (`TEST-100-AAAA`
  и т.п.) — он **не подключён** в `index.js` (подключён только
  `apiV1Routes.js`). Похоже на неиспользуемый/устаревший файл. См.
  [OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md).
- Автоматических тестов (jest/mocha/vitest и т.п.) в проекте нет. Есть
  несколько ручных Node-скриптов в корне `activation-system/` (`test-account-
  deletion.js` и др.) для ad-hoc проверки конкретных сценариев вручную.
- Известные проблемы безопасности были задокументированы отдельно ранее (см.
  память агента / прошлый аудит от 2026-08-01: секреты в git-истории,
  Postgres на `0.0.0.0:7440`, IDOR на чеках). Эта задача (TASK-0001) их не
  устраняла и не проверяла заново по существу — только зафиксировала то, что
  видно напрямую (например, `test-payme-transaction.sh` с зашитым ключом
  Payme всё ещё в git, порт БД 7440 всё ещё проброшен на все интерфейсы).
  См. [STATUS.md](docs/STATUS.md) и [OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md).
