## Что подтверждено и работает

- **Backend** — один Express-процесс в контейнере `mibt2-app`, обслуживает и
  SSR (EJS), и JSON API (`/api/*`). Работает в проде **2 недели без
  перезапуска** на момент проверки. Логика лежит прямо в `routes/**/*.js` —
  каталог `controllers/` есть в дереве, но полностью пуст.
- **77 объявленных HTTP-маршрутов** в 13 файлах роутеров (29 из них — в
  одном `routes/api/admin/index.js`) — задокументированы в
  [API.md](API.md).
- **Схема данных**: 18 моделей, 9 enum'ов, 3 применённые Prisma-миграции
  (с 2026-06-08 по 2026-06-13) — задокументированы в
  [DATABASE.md](DATABASE.md). Деньги — `BigInt` в тийинах.
- **Аутентификация**: email + пароль (bcrypt), сессии в PostgreSQL
  (`connect-pg-simple`), 2 роли (`ADMIN`/`CUSTOMER`). Восстановление пароля —
  email + одноразовый OTP.
- **Бизнес-модель**: два типа клиента — `CORPORATE` (баланс: пополнение →
  заморозка при заказе → списание при доставке) и `BUDGET`/B2G (постоплата,
  баланс не используется вовсе — подтверждено в `order.service.js`).
- **Документы и КП**: генерация PDF-спецификации (PDFKit), ручная загрузка
  файлов администратором/клиентом, скачивание строго через одноразовые
  токены (TTL 5 минут).
- **Деплой**: 4 Docker-контейнера (`app`, `postgres`, `nginx`, `db-backup`),
  все подняты и здоровы. TLS для `portal.mibt.uz` — Let's Encrypt, годен до
  2026-11-10. Ежедневные бэкапы БД идут вплоть до сегодняшнего дня.
  Подробности — [DEPLOYMENT.md](DEPLOYMENT.md).

## Известные проблемы / расхождения (подтверждены напрямую)

1. **`assignLicensesToOrder` (автоматическая выдача лицензий из пула
   `ProductLicense`) — мёртвый код.** Функция определена и импортирована, но
   нигде не вызывается; реальный флоу выдачи ключей — ручной, через
   `POST /api/admin/orders/:id/lines/:lineId/licenses`, что подтверждается
   отдельным changelog-документом самого проекта
   (`docs/CHANGELOG_KEY_DELIVERY_REFACTOR.md`, 2026-06-10). При этом
   API для наполнения пула лицензиями всё ещё активен и не убран.
2. **Верхнеуровневая документация проекта (`PRD.md`, `ARCHITECTURE.md`,
   `BUSINESS_LOGIC.md`, `USER_FLOWS.md`, `BUILD_SPEC.md`) датирована
   2026-06-08** и не была обновлена вслед за как минимум двумя более
   поздними изменениями кода, зафиксированными отдельными
   changelog-документами в `docs/`. Построчная сверка не проводилась.
3. **CSRF-защиты не найдено** ни в зависимостях, ни в коде.
4. **Нет автоматических тестов** (`jest`/`mocha`/`vitest` не найдены в
   зависимостях, файлов `*.test.js`/`*.spec.js` не обнаружено) и **нет CI**
   (`.github/workflows` отсутствует).
5. **`/home/admin1/mibt-2/` не является git-репозиторием** — история
   изменений кода не отслеживается системой контроля версий.
6. **Развитие кода остановлено ~3 месяца назад**: по mtime файлов последние
   правки — 13 июня 2026, при этом прод стабильно работает и получает
   реальный трафик (судя по активным бэкапам и uptime контейнеров).
7. **Два независимых nginx** (system nginx хоста для публичного трафика +
   `mibt2-nginx` внутри Docker Compose на `127.0.0.1:3011` с self-signed
   TLS) — назначение второго не подтверждено документально, похоже на
   аварийный путь доступа.
