# ADR-0007: Отказ закрытия при неподдерживаемой валюте банка

Дата: 2026-09-10. Статус: реализовано локально, не выпущено. TASK-0005.

## Причина

Шаг 5 обрабатывает только USD. Отсутствие USD ошибочно трактовалось как отсутствие
валютных счетов; EUR мог приводить к сохранению нуля и продолжению закрытия.

## Решение

- Step5 различает отсутствие иностранных банков, USD и неподдерживаемые валюты.
  Последние блокируют продолжение; ошибки загрузки/формата дают отказ с повтором.
  Пересоздание по periodId и проверка активности исключают поздний переход.
- saveClosingState при fxDiff и finalizePeriod внутри транзакции до записей
  проверяют BankAccount по orgId и currency notIn UZS/USD. Даже нулевой остаток
  блокируется: доказательства отсутствия валютной позиции за период нет.
- Оба API закрытия проверяют текущее членство и OWNER/ADMIN/ACCOUNTANT, строгий
  JSON и принадлежность периода. finalize возвращает PostingValidationError 400
  и сохраняет MissingCogsError 409; принудительное закрытие запрещено.

## Ограничения

Текущая BankAccount.currency не является историческим регистром. Конкурентная
смена валюты/создание счёта не сериализованы с проверкой. Валютные долги,
неденежные авансы, исторические курсы и расчёт USD по НСБУ №22 не реализованы
этим решением. Закрытые периоды и исторические суммы не переписываются.
Проверены unit/API и 4 дополнительных PostgreSQL-сценария: отказ с полным
сохранением состояния для EUR/RUB и отсутствие влияния чужого EUR.
ACC-007 и бухгалтерская приёмка остаются открытыми.
