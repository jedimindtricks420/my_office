  JWT (`jose`) в cookie `v2_session`, без Next.js middleware.

## Известные расхождения между документацией проекта и реальностью
## (подтверждены прямой проверкой, не предположения)

1. **v1 (legacy) фактически запущен на хосте**, хотя README называет его
   остановленным, а каталог `src/` физически отсутствует в репозитории.
   `docker ps` показывает два запущенных контейнера (`contador-app`,
   `f7ee8a3d81b8_contador-app`, последний на порту 3030), собранных из более
   ранних образов (2026-05-28 и 2026-06-12). См.
   [DEPLOYMENT.md](DEPLOYMENT.md) и [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md).
2. **PM2 не используется**, хотя внутренняя документация проекта
   (`docs/01_PROJECT_OVERVIEW.md`, `docs/02_ARCHITECTURE.md`, датированы
   концом июня 2026) описывает v2 как работающий через PM2. `pm2 list`
   (2026-09-05) — пустой список процессов. Более новый README проекта
   (2026-07-05) уже корректно указывает Docker Compose.
3. **AI-провайдер — Azure OpenAI, не публичный OpenAI**, вопреки тому, как
   это обычно читается из README (упоминается `OPENAI_API_KEY` для v2).
   Реальный `v2/.env` содержит `AZURE_OPENAI_ENDPOINT`/`AZURE_OPENAI_API_KEY`,
   и код (`aiClassifier.ts`) явно указывает `baseURL` на Azure AI Foundry.
4. **Размер AI-батча — 100 транзакций**, а не «до 20», как написано в README.
   Подтверждено константой `AI.BATCH_SIZE` в `v2/src/lib/constants.ts`.
5. **Третий платёжный провайдер — Alifpay** — реализован в
   `admin/server.ts` (обработчики создания счёта, чекаута, проверки подписи,
   отдельный вебхук), но не упомянут в README рядом с Payme/Click.
6. **`docs/01_PROJECT_OVERVIEW.md`/`02_ARCHITECTURE.md` устарели** примерно
   на 7-9 дней относительно README и заметно отстают от самых новых
   технических доков в `v2/docs/modules/` (датированы серединой-концом июля,
   `v2/docs/DOCUMENT_TYPES.md` — 19 августа). `docs/04_API_REFERENCE.md`
   (753 строки) тоже, вероятно, устарел: 42 из 78 файлов маршрутов v2 имеют
   более позднюю дату изменения, чем этот документ.
