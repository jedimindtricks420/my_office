## Домен

Мультитенантная SaaS-система бухгалтерского учёта для Узбекистана, построенная на
принципе двойной записи по **НСБУ №21** (Национальный стандарт бухгалтерского учёта,
рег. МЮ №3593, с 01.01.2025) и **НСБУ №1** (рег. МЮ №3544, с 01.01.2025).
Домен: `contador.uz`.

## Ключевая функциональность v2 (по README и коду)

- **Форма №1** (Бухгалтерский баланс) и **Форма №2** (Отчёт о финансовых результатах)
  по НСБУ №21 — реализованы прямыми SQL-агрегатами по `JournalEntry`
  (`v2/src/app/api/reports/balance/route.ts`, `v2/src/app/api/pnl/route.ts`).
- **Два налоговых режима**: НДС + налог на прибыль (`taxRegime: VAT`) и налог с оборота
  (`taxRegime: TURNOVER_TAX`) — переключается на уровне организации
  (модель `Organization`, поля `taxRegime`, `isVatPayer`, `turnoverTaxRate`).
- **Импорт банковских выписок**: форматы 1CClientBankExchange (.txt) и Excel
  (Asaka, Kapital, Ipak Yoli), SHA-256 дедупликация, откат по `importBatchId`.
- **AI-классификация операций**: движок правил (INN → KEYWORD → AMOUNT_RANGE →
  TREASURY_ACCOUNT) + LLM-классификатор. Подтверждено кодом: провайдер —
  **Azure OpenAI** (Azure AI Foundry, через `AZURE_OPENAI_ENDPOINT`/
  `AZURE_OPENAI_API_KEY`), модель по умолчанию `gpt-4o-mini`
  (`OPENAI_MODEL`), размер батча **100** транзакций (константа `AI.BATCH_SIZE`
  в `v2/src/lib/constants.ts`) — это расходится с описанием в README проекта
  ("батчи до 20 транзакций"); порог уверенности по умолчанию 70%
  (`AI.CONFIDENCE_THRESHOLD`, переопределяем на уровне организации).
- **Мастер закрытия месяца** — 7 шагов (импорт → классификация → реестр →
  начисления → курсовые разницы → сверка с Soliq → финализация), модель
  `ClosingJob` хранит прогресс по шагам (`v2/prisma/schema.prisma`).
- **Годовое закрытие** — перенос 9910 → 8710, доступно только для декабря с уже
  закрытым периодом (`POST /api/closing/year-end`).
- **Открытые позиции** (авансы, подотчёт, депозиты, дивиденды) с дедлайнами и
  автоматическим статусом RISK — модель `OpenItem`.
- **Платежи и подписки**: три платёжных провайдера подтверждены в коде
  admin-приложения — **Payme, Click и Alifpay** (README упоминает только Payme и
  Click; Alifpay подтверждён отдельно кодом `admin/server.ts` и полями
  `alif_*` в модели `PaymentConfig`).
