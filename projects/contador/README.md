# Contador

Документация проекта Contador внутри `my_office`. Сам код проекта живёт вне этого
репозитория — см. [AGENTS.md](AGENTS.md).

## Что это

Мультитенантная бухгалтерская SaaS-система для Узбекистана (двойная запись,
НСБУ №1/№21), с AI-классификацией банковских транзакций. Подробнее —
[docs/OVERVIEW.md](docs/OVERVIEW.md).

## Текущее состояние на 2026-09-11

**Разработка продолжается. Проект не прошёл полную бухгалтерскую приёмку;
локальные исправления TASK-0005 не выпущены в production.**

- Последний этап: защищён первичный ввод начальных остатков, изолированы
	счётчики счетов, добавлены просмотр и экспорт банковского архива;
	RU/UZ-описания банковского импорта согласованы с TXT-only.
- Подтверждённые тесты и границы проверок: [текущий статус](docs/STATUS.md).
- Оставшиеся работы: неизменяемое сторно и версии, частичные расчёты,
	аналитические и налоговые регистры, полная проверка доступа и приёмка.
	Все 57 требований ещё не приняты, G0–G4 не пройдены:
	[матрица требований и план завершения](docs/PROGRESS-2026-09-11.md).
- Активная задача: [TASK-0005](tasks/active/TASK-0005-accounting-correctness-remediation.md).
	Публикация этой документации не означает публикацию кода или обновление сервиса.
