# drweb-key-service

Микросервис централизованной генерации лицензионных ключей Dr.Web через
партнёрский API (`f2.drweb.com/remotekeys/`) — прослойка между внутренними
проектами (например, Telegram-ботами продаж) и Dr.Web, с веб-панелью
администрирования ассортимента и истории выданных ключей.

Это каталог документации в `my_office`. Исходный код — отдельно, вне этого
репозитория, см. [AGENTS.md](AGENTS.md).

## С чего начать

   делать.

4. [docs/OPEN_QUESTIONS.md](docs/OPEN_QUESTIONS.md) — что не удалось
   подтвердить.
