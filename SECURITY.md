# Security

Не публикуй секреты, токены, пароли, ключи, персональные данные или другую конфиденциальную информацию в репозитории, задачах и Pull Request.

Если найден секрет или потенциальная уязвимость:

1. Не добавляй её в commit и не распространяй её содержимое.
2. Ограничь доступ к информации.
3. Зафиксируй только необходимые безопасные сведения.
4. Сообщи владельцу репозитория через приватный канал.

Для уязвимостей в конкретном проекте применяй дополнительные инструкции из его документации и runbooks.
