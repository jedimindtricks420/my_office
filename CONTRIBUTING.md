# Contributing

## Общий порядок

1. Определи проект и границы изменения.
2. Прочитай корневой `AGENTS.md` и инструкции проекта.
3. Создай отдельную ветку для связанного изменения.
4. Внеси минимально необходимое изменение.
5. Проверь diff, ссылки, структуру и релевантные проверки.
6. Обнови задачу и документацию текущего состояния, если это требуется.
7. Открой Pull Request в `main` с кратким описанием изменения и выполненных проверок.

## Документация

Документация должна отражать подтверждённое текущее состояние. Архитектурные решения, влияющие на систему, оформляются отдельными ADR.

## Область изменений

Не изменяй другие проекты и общие ресурсы без необходимости, связанной с задачей. Не добавляй секреты и учётные данные.
